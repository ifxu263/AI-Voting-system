# AI-Powered Online Voting System

A secure, full-stack digital voting platform with OpenCV-based facial verification, built using Python Flask and SQLite.

## 🚀 Key Features
- **AI Facial Verification:** OpenCV Haar Cascade algorithm for detecting single human faces during voter registration.
- **Role-Based Access Control (RBAC):** Admin dashboard for managing elections/candidates & secure voter authentication.
- **Fraud & Duplicate Prevention:** SQLite unique constraint rules and secure session management.
- **Live Camera Integration:** WebRTC camera capture support.

## 🛠️ Tech Stack
- **Backend:** Python 3.10+, Flask
- **AI / Computer Vision:** OpenCV (cv2)
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3, JavaScript, SweetAlert2
